## PCB Test Report Generator

Included features
- PCB images: Upload front and back PCB photographs.
- Custom test parameters: Add or remove unlimited test entries.
- Test status: Pass, Fail, N/A and Pending.
- Remarks: Add detailed observations and measured values.
- Test evidence: Optional individual photographs for each test.
- Two test categories: Electrical / Power Testing and Functional Testing.
- PDF export: A4 or Letter, Portrait or Landscape.
- Automatic summary: Counts Pass, Fail, N/A and Pending results.
